# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-11-11

### Added

- Multi-sport scores and schedules across 34 competitions.
- Live view scanning followed leagues and showing only games in progress.
- Conference and pool standings per league.
- Match sheet with goal scorers, assists, cards, and key statistics.
- Upcoming matches calendar.
- League search.
- Five text size levels.
- Optional league logos in the sidebar and header.
- Palette and language inherited live from Omarchy.
- English and French interface.
- Linux x86_64 and arm64 builds produced by CI.

### Known limitations

- Depends on the unofficial ESPN API (no SLA).
- No persistent offline mode.
- No notifications.
